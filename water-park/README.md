# สวนน้ำเจ๊แป๊ว — Jae Paew Water Park

เว็บไซต์หน้าเดียว (single-page) ดีไซน์สไตล์ Apple / สวนสนุก สำหรับสวนน้ำเจ๊แป๊ว

## วิธีดู
เปิดไฟล์ `index.html` ด้วยเบราว์เซอร์ได้เลย (ดับเบิลคลิก) — ไม่ต้องติดตั้งอะไร

## โครงสร้าง
- `index.html` — ทั้งหน้าเว็บ (HTML + CSS + JS ในไฟล์เดียว)
- `images/` — รูปจริงของสวนน้ำ (สไลเดอร์, สระ, เด็กเล่นน้ำ, คาเฟ่ JOY UP)

## ข้อมูลในเว็บ
- เปิดทำการ: เสาร์–อาทิตย์ 10:00–19:00 น.
- เด็กเล็ก (ไม่ถึง 120 ซม.): 50 บาท
- เด็กโต (120 ซม. ขึ้นไป): 80 บาท
- มีชุดว่ายน้ำให้เลือกเช่า
